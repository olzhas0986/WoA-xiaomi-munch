# License map

The repository is not uniformly licensed. The root `LICENSE` applies to new
project code unless a file carries a different SPDX identifier or an embedded
license notice. Those file-level notices take precedence.

| SPDX identifier | Used by |
|---|---|
| `BSD-2-Clause` | New project code covered by the root `LICENSE` |
| `BSD-2-Clause-Patent` | Project Mu, EDK II derived UEFI files and host tests |
| `BSD-3-Clause` | Reference Linux device trees |
| `GPL-2.0-only` | Reference Linux drivers, patches and diagnostic helpers |
| `GPL-2.0-only OR BSD-2-Clause` | Dual-licensed reference device-tree material |
| `APSL-2.0` | The adapted USB probe descriptor table identified in `THIRD_PARTY.md` |

Canonical license texts and identifiers are maintained by the SPDX project:
<https://spdx.org/licenses/>. Redistributors must preserve each file's SPDX
identifier, copyright notices and any embedded license text. Binary distributors
must also satisfy the corresponding source, notice and documentation duties.
